# ⛽ Petrol Price Analysis

## 📌 Project Overview
This project analyzes petrol price data to identify price trends, variations, and useful insights using Python and data analysis techniques.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Key Features
- Petrol price trend analysis
- Data cleaning and preprocessing
- State-wise price comparison
- Data visualization
- Identification of important trends and insights

## 📁 Project File
`project 02.ipynb` – Contains the complete analysis and visualizations.
